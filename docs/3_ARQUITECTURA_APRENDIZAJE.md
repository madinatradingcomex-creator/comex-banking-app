# 🧠 Arquitectura de Aprendizaje Continuo del Sistema

El sistema evoluciona mediante 4 motores de retroalimentación:

```
1. MOTOR NORMATIVO (Actualización BCRA / ARCA)
   └── Monitoreo automatizado de Comunicaciones "A" y Textos Ordenados.

2. MEMORIA DE CRITERIOS BANCARIOS (Santander, Galicia, Macro, etc.)
   └── Registro de requisitos y modelos documentales específicos por entidad financiera.

3. PERFIL HISTÓRICO DEL CLIENTE (Personalización Predictiva)
   └── Seguimiento de NCMs usuales, candados MEP/CCL y cruce automático de anticipos B02.

4. BASE DE CASOS Y JURISPRUDENCIA (RAG con Ley 19.359)
   └── Repositorio de descargos y argumentos legales para casos complejos y sumarios.
```
